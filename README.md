# AIライティングツール

Gemini APIを使った個人用オールインワン・ライティング支援ツール（Streamlit製）。

## 機能

- 📝 ブログ執筆
- 📧 メール返信
- 📄 要約
- ✏️ 添削
- 🌐 翻訳
- 🎨 トーン・文体変換
- 💡 タイトル・見出し生成
- 🧩 箇条書き展開

## セットアップ

```bash
pip install -r requirements.txt
```

`.env.example`を`.env`にコピーし、Gemini APIキーを設定してください。

```bash
cp .env.example .env
```

```
GEMINI_API_KEY=あなたのAPIキー
```

`.env`を設定しない場合でも、アプリ起動後にサイドバーからその場でAPIキーを入力できます（保存はされません）。

## 起動方法

```bash
streamlit run app.py
```

ブラウザが自動で開き、`http://localhost:8501` でアプリが利用できます。

## ⚠️ 注意事項（セキュリティ）

このアプリには認証機能が一切ありません。個人・単一ユーザーがローカル（`localhost`）で使うことを前提に設計されています。

`--server.address 0.0.0.0` を指定しての起動や、ポート開放・クラウドVM上でのホスティングなど、**LANやインターネットから到達可能な形で公開しないでください**。公開すると、URLを知っている第三者が認証なしで全機能を使えてしまい、あなたのGemini APIキーが無制限に消費されてしまいます。
